# Единый реестр объекта: каждый факт вводится один раз

Цель: один Excel-файл на объект, из которого собираются все документы ПТО —
акты скрытых работ, общий журнал работ, журнал входного контроля, формы 2 и 3, М-29, реестр ИД.
Сейчас у каждого инструмента свой файл, и одни и те же данные вводятся по 2–3 раза.

## Где сейчас дублируется ввод

| Данные | Где вводятся сейчас |
|---|---|
| Работы (что, где, когда) | реестр АОСР «Работы» + план-факт «Выполнение» + журнал (другая сессия) |
| Материалы и сертификаты | реестр АОСР «Материалы» + М-29 «Материалы»/«Поступление» (разные коды: M01 и MAT01) |
| Объект, организации | реестр АОСР «Объект» + план-факт «Настройки» + М-29 «Настройки» |
| Люди (СМО, технадзор…) | реестр АОСР + журнал |
| Номер АОСР у объёма | вручную в план-факте, хотя он уже есть в реестре |

## Модель данных: 6 листов, каждый факт в одном месте

| Лист | Одна строка = | Вводится | Используют |
|---|---|---|---|
| **Объект** | параметр объекта; колонка «Люди» | один раз на объект | все документы |
| **Смета** | позиция сметы (позже — импорт из АВС-РК) | один раз | формы 2–3, М-29, проверка перевыполнения |
| **Работы** | работа на участке за период | по мере выполнения | АОСР, общий журнал, формы 2–3, М-29, реестр ИД |
| **Поступления** | партия материала по накладной + документ о качестве | при приёмке материала | АОСР п. 3, журнал входного контроля, М-29 (приход) |
| **Нормы** | позиция сметы × материал × норма | один раз (позже — из АВС-РК) | М-29 |
| **Остатки** | материал на конец месяца | раз в месяц | М-29 |

### Лист «Работы» — центр всего
Колонки (новые — **жирным**):
Формировать · Наименование · Участок · Место · Чертежи · Материалы (коды партий) ·
Представитель СМО · Представитель технадзора · … (как сейчас) ·
**№ поз. сметы** · **Объём** · **Нужен АОСР (да/нет)**

- Строка со «Нужен АОСР = да» → акт скрытых работ.
- Строка с позицией сметы и объёмом → объём в формах 2–3 и списание в М-29.
- Строка с датами и людьми → запись в общем журнале работ.
- № АОСР в формах 2–3 и в журнале подставляется сам — из той же строки.

### Лист «Поступления» вместо двух «Материалов»
Код партии · Материал · Кол-во · Ед. · Дата поступления · № накладной · Поставщик ·
Вид документа о качестве · № · Дата · Действует до · Результат входного контроля

- В АОСР п. 3 материал указывается кодом партии → в акт идёт её документ о качестве.
- Журнал входного контроля = этот лист, отформатированный по форме.
- М-29: приход за месяц = сумма поступлений.

## Что считается само (ввода нет)
№ актов · последующие работы · реестр ИД · перечень актов в общем журнале ·
№ АОСР у объёмов · объёмы с начала строительства/года/месяца · расход по нормам ·
фактический расход · перекрёстные проверки.

## Перекрёстные проверки (появляются только при едином реестре)
- объём предъявлен в форме 2, а АОСР по нему нет (или не подписан — «Формировать» = нет и нет номера);
- в акте материал, которого нет в поступлениях до даты начала работ;
- даты акта не попадают в записи общего журнала;
- использовано материала больше, чем поступило (по партии);
- представитель в акте не совпадает с журналом за эти даты.

## Один HTML вместо трёх
«ПТО-пульт»: загружаете один файл объекта → кнопки «Акты скрытых работ», «Общий журнал»,
«Журнал входного контроля», «Формы 2 и 3», «М-29», «Сверка». Общий код чтения Excel и проверок.

## Порядок перехода (по шагам, без поломки текущих файлов)
1. ✅ **Поступления** — общий лист материалов для АОСР и М-29 (единые коды). Старый лист «Материалы» продолжает читаться.
2. **Смета + «№ поз. сметы»/«Объём» в «Работах»** — формы 2–3 читают «Работы», лист «Выполнение» не нужен.
3. ✅ **Общий журнал и журнал входного контроля** — из «Работ» и «Поступлений»; выгрузка в журнал производства работ (`templates/zhurnal-proizvodstva-rabot`) и сверка журнал ↔ акты.
4. 🔄 **«ПТО-пульт»** — готов (`dist/ПТО_пульт.html`: акты и журналы, журнал работ, формы 2–3). Осталось: **М-29 в HTML** отдельной вкладкой.
5. **Импорт сметы и норм из АВС-РК** — когда будет выгрузка.

Каждый шаг совместим со старыми реестрами: колонки ищутся по названию.
