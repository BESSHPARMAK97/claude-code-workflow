ОТЧЁТ О РАСХОДЕ МАТЕРИАЛОВ (М-29) — МАКЕТ С УСЛОВНЫМИ НОРМАМИ

Объёмы работ НЕ вводятся заново: они берутся из ../forms_2_3/план_факт.xlsx
(листы «Смета» и «Выполнение»). Поэтому папки m29 и forms_2_3 должны лежать рядом.

Материалы и приход тоже НЕ вводятся заново: они берутся с листа «Поступления»
реестра объекта ../aosr/реестр_работ.xlsx — того же, по которому формируются АОСР.
Код материала = код партии до «-» (M12-1 и M12-2 — это материал M12).

Листы материалы.xlsx:
  Настройки    — отчётный период, путь к план-факту, путь к реестру («Файл реестра»),
                 допустимый перерасход (%), подписанты.
  Нормы        — № позиции сметы -> код материала (M12, M07…) -> норма расхода на единицу работ.
                 На одну позицию — сколько угодно материалов. Сейчас нормы УСЛОВНЫЕ — замените своими.
  Остатки      — фактические остатки на конец каждого месяца (инвентаризация/замер).
  Если «Файл реестра» пуст — читаются старые листы «Материалы» и «Поступление» (если они есть).
                 Нужны остатки на конец ПРЕДЫДУЩЕГО и ОТЧЁТНОГО месяца.

Как считается:
  Расход по нормам   = объём работ за месяц × норма
  Фактический расход = остаток на начало + поступило − фактический остаток на конец
  Отклонение         = факт − норма (+ перерасход / − экономия)

Результат (папка «М-29_ГГГГ-ММ»):
  М-29.xlsx — Раздел 1 (расход по нормам по работам), Раздел 2 (сопоставление по материалам,
              перерасход сверх допуска красным, экономия зелёным, сумма перерасхода в тенге),
              лист «По участкам» (нормативный расход по блокам и этажам — где искать перерасход).
  Отчёт_проверки.txt

Отчёт НЕ формируется при ошибках: нет остатка на начало/конец месяца, остаток больше, чем было
с поступлением, материал не из справочника.
Предупреждения: перерасход сверх допуска, расход материала без выполненных работ,
работы без норм (материалы по ним не списываются), поступление без № накладной.

ВАЖНО: вид отчёта условный (логика М-29). Пришлите ваш заполненный М-29 — подгоню колонки и подписи.
