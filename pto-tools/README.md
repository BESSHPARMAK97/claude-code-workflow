# Инструменты инженера ПТО

Автоматизация исполнительной документации и отчётности для строительства в Казахстане.
Готовые к работе файлы лежат в [`dist/`](dist/) — их можно просто скачать и открыть.

| Инструмент | Готовый файл | Что делает |
|---|---|---|
| **ПТО-пульт** | `dist/ПТО_пульт.html` | Всё в одном файле: вкладки «Акты и журналы», «Журнал работ», «Формы 2 и 3». Журнал — быстрая запись (дата, работа, этаж, объём) и общий список работ; акты формируются по работам журнала (см. ниже). Перетаскиваете реестр или план-факт — пульт сам открывает нужную вкладку |
| Генератор АОСР | `dist/Генератор_АОСР.html` | Реестр Excel → комплект актов в Word: освидетельствования скрытых работ (Приложение Д к СН РК 1.03-00-2022) и промежуточной приёмки ответственных конструкций (Приложение Е) |
| Формы 2 и 3 | `dist/Формы_2_и_3.html` | План-факт Excel → акт выполненных работ (ф. 2), справка о стоимости (ф. 3), расшифровка по участкам |
| М-29 (макет) | `m29/` (Python) | Списание материалов: расход по нормам против фактического; приход — из «Поступлений» реестра |
| Видео-инструкция | `dist/Видео_инструкция_АОСР.mp4` | Как пользоваться генератором АОСР |

HTML-файлы автономные: работают в любом браузере без интернета и установки, данные никуда не отправляются.

## Генератор АОСР — кратко

Реестр `реестр_работ.xlsx`, три листа:

- **Объект** — объект, город, основная СМО, проектная организация, первый номер акта, порог «материалы в приложение»; в колонке D — список представителей для выпадающих списков.
- **Работы** — одна строка = один акт. Обязательные: Наименование, Участок, Место, Чертежи, Материалы (коды), Представитель СМО, Представитель технадзора. Необязательные: № акта (автонумерация), даты (пусто — прочерк под ручку), доп. доказательства, отклонения, последующие работы (пусто — из следующего акта на участке), авторский надзор и субподрядчик (пусто — нет в акте), организация СМО. «Формировать = нет» — акт не пересобирается, номер сохраняется.
- **Поступления** — одна строка = партия по накладной с документом о качестве (код, количество, дата поступления, поставщик, срок действия). Код без номера партии (M04) берёт все партии (M04-1, M04-2). Этот же лист — источник прихода для М-29.

Проверки: обязательные поля, повтор номеров, даты (начало/окончание/акт), документ о качестве позже акта или истёк, материал не найден, формат «Должность Организация: Фамилия И.О.».
Если материалов больше порога — в п. 3 «согласно приложению», за актом лист приложения.

### Журналы из того же реестра

После загрузки реестра на странице генератора:

- **Журнал входного контроля** — Word, альбомный лист, из «Поступлений»: дата, материал, количество, поставщик и накладная, документ о качестве со сроком, результат контроля. Предупреждает о пропущенной накладной, результате контроля, истёкшем к поступлению документе.
- **Для журнала работ (.json)** — файл для [журнала производства работ](../templates/zhurnal-proizvodstva-rabot/): титул (объект, генподрядчик, проектировщик, технадзор, авторский надзор, субподрядчики), раздел 1 — ИТР подрядчика и субподрядчиков, раздел 3 — перечень актов, раздел 4 — работы с датами. Открывается в журнале кнопкой «Открыть файл».
- **Дополнить мой журнал…** — загружаете свой `.json` журнала: добавляется только недостающее (ИТР, акты, записи), ручные данные не меняются. Заодно сверка: за период работ по акту в журнале нет записей, дата акта в журнале и реестре различается, акт есть в журнале, но не в реестре.
- **Связь записей с актами.** У записи раздела 4 — номер её акта (графа «АОСР №»). В старом журнале номер проставляется при дополнении, если графа пустая.
- **В ПТО-пульте** кнопка «Передать в журнал работ» дописывает данные реестра в журнал (по желанию; сам журнал из реестра не заполняется).

## ПТО-пульт: журнал работ и акты из одного списка работ

1. **Реестр Excel объекта загружается один раз** (перетащить в пульт): из него запоминаются люди и организации (лист «Объект») и материалы с документами о качестве («Поступления»). Если в реестре есть работы — по ним, как раньше, сразу собираются акты.
2. **ИТР и ПТО ведут журнал** («Журнал работ» → раздел 4): строка быстрой записи — дата, работа (из списка или новая), этаж, объём. Оси, отметки, погода, исполнитель, данные спецжурналов — в «Подробнее», можно позже. Плашка показывает дни без записей за неделю и краснеет при отставании больше 5 дней; «работ не было» закрывает день. «Печать раздела 4» за период — для переписывания в бумажный журнал.
3. **ПТО отмечает акты** («Работы и акты»): у работы — вид акта (скрытых работ или промежуточной приёмки ответственных конструкций), № акта, чертежи, материалы, представители (из реестра). Даты акта — первая и последняя запись журнала по работе, этажи — из записей. Акт сразу появляется в разделе 3, его номер — в записях.
4. **«Сформировать акты (Word)»** — комплект по работам с отметкой; проверки те же, что у генератора.

### Акт промежуточной приёмки ответственных конструкций

Колонка «Вид акта» в «Работах» реестра (необязательная): «промежуточной приёмки» — акт по форме промежуточной приёмки ответственных конструкций (Приложение Е к СН РК 1.03-00-2022), пусто или «АОСР» — акт скрытых работ. В форме промежуточной приёмки комиссия из представителей СМО, технадзора и проектной организации; пунктов о материалах и доп. доказательствах нет. Шаблон `aosr/template_ppk.docx` собирается из шаблона АОСР скриптом `tools/make_ppk_template.py`. Текст формы взят из СН РК 1.03-00-2011 (Приложение Д, ИС «Параграф», ред. 21.04.2020): официальный текст редакции 2022 г. в открытом доступе найти не удалось — сверьте с ним и с требованиями технадзора.

## Сборка из исходников

```bash
npm install
python3 tools/build.py      # собирает dist/*.html
npm test                    # прогон в браузере (нужен Playwright + Chromium); журнал берётся из ../templates/zhurnal-proizvodstva-rabot
```

Структура:

```
aosr/        исходники генератора АОСР: app.js, shell.html, template.docx (поля {…} для docxtemplater), build_registry.py
forms_2_3/   исходники форм 2 и 3: app.js, shell.html, примеры план-факта
m29/         генератор М-29 (Python, openpyxl), читает ../forms_2_3/план_факт.xlsx
video/       сборка видео-инструкции (скриншоты Playwright, озвучка RHVoice, ffmpeg) — см. video/README.md
tests/       браузерные тесты и эталонные реестры
pult/        ПТО-пульт: вкладки-фреймы с готовыми инструментами, общая загрузка файлов
tools/       build.py — сборка dist/
dist/        готовые файлы для пользователей
```

Библиотеки (встраиваются в HTML при сборке): SheetJS `xlsx` 0.18.5, `docxtemplater` 3.47.4, `pizzip` 3.1.7, `exceljs` 4.4.0.

## Ограничения

- Форма акта собрана по образцу комплекта, оформленного по Приложению Д; сверяйте с требованиями вашего заказчика и технадзора.
- Формы 2 и 3, М-29 — макеты на условных данных; вид будет подогнан под бланки заказчика и выгрузку сметы АВС-РК.
- Проверено: 3000 актов собираются в браузере примерно за 20 секунд; Word на комплектах больше 1000 страниц работает медленно — формируйте порциями.
