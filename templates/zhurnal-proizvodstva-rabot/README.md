# Журнал производства работ (СН РК 1.03-00-2022)

Шаблон журнала производства работ по форме Приложения В к СН РК 1.03-00-2022 со спецжурналами: бетонных работ, ухода за бетоном, сварочных работ и антикоррозионной защиты. Сделан в двух форматах.

| Файл | Что это |
|---|---|
| `zhurnal-proizvodstva-rabot.html` | Веб-версия. Открывается в любом браузере, работает без интернета |
| `zhurnal-proizvodstva-rabot.xlsx` | Версия для Excel |
| `generate_xlsx.py` | Скрипт, который собирает `.xlsx` (нужен `openpyxl`) |

## Состав

- Титульный лист.
- Раздел 1 — список ИТР.
- Раздел 2 — перечень специальных журналов.
- Раздел 3 — акты скрытых работ и промежуточной приёмки.
- Раздел 4 — сведения о производстве работ.
- Раздел 5 — замечания надзора; статус замечания считается автоматически.
- Спецжурналы: бетонных работ, ухода за бетоном, сварочных работ, антикоррозионной защиты.

## Как связаны раздел 4 и спецжурналы

Журнал для записи раздела 4 определяется по описанию работ: «бетонирование» — журналы бетона, «сварка» — журнал сварочных работ, «антикоррозионная защита», «огрунтовка» — журнал антикоррозионной защиты. Если определилось неверно, журнал выбирают вручную.

Данные спецжурналов можно вносить прямо в разделе 4, они не печатаются в составе раздела:
- в HTML — в раскрывающейся строке под записью или на вкладке журнала;
- в Excel — в столбцах справа от таблицы раздела 4. Листы спецжурналов заполняются формулами.

## HTML-версия

- Записи автоматически сохраняются в браузере. Резервная копия — кнопка «Сохранить файл» (`.json`), загрузка — «Открыть файл».
- «Печать / PDF» печатает журнал в формате бланка (A4), «Экспорт в Word» сохраняет `.doc`.
- Под таблицами показываются подсказки о пропусках и нарушениях: хронология, просроченные замечания, прочность бетона ниже проектной, влажность при окраске и т. п.

## Пересборка Excel

```bash
python3 generate_xlsx.py
```

## Важно

Текст Приложения В СН РК 1.03-00-2022 при создании шаблона получить не удалось. Названия граф разделов 1–5 составлены по форме СН РК 1.03-00-2011 и практике её применения. Перед использованием на объекте сверьте их с официальным текстом нормы.
